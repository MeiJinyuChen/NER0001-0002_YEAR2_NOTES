# 2. Structural Organisation of Hippocampal Formation

## 2.1 Components

### (A) Hippocampus (3-layered Allocortex)
- Dentate Gyrus (DG) - main input place
- CA3
- CA1
- Subiculum - main output place
### (B) Periallocortex
<font color="#245bdb"> L4 is cell-free (only contains fibres)</font>
- Presubiculum (PrS)
- Parasubiculum (PaS)
- **Entorhinal cortex (EC)** (medial + lateral entorhinal area; main interface between neocortex and hippocampus, for both input and output)
### (C) Proisocortex
<font color="#245bdb">Similar to but not quite neocortex: different L4</font>
- Perirhinal cortex (A35, A36)
- Parahippocampal cortex = Postrhinal cortex (in rodents)

Information flow:
Neocortex → Proisocortex (perirhinal cortex, parahippocampal cortex) → Entorhinal cortex → Dentate gyrus → CA3 → CA1 → Subiculum

## 2.2 Terminology
- Hippocampus proper = allocortex only
- Hippocampal formation = ALL above structures

# 3. Intra-Hippocampal Connectivity

## 3.2 Tri-synaptic Loop (Unidirectional Flow)

| ![[Pasted image 20260411061652.png\|325]] | ![[Pasted image 20260411062345.png\|375]] |
| ----------------------------------------- | ------------------------------------ |
**EC → DG → CA3 → CA1 → EC**
- EC → DG = **Perforant pathway**
- DG → CA3 = **Mossy fibres**
	- Granule cells (DG) → Pyramidal cells (CA3). Note: not from mossy cells in DG.
- CA3 → CA1 = **Schaffer collaterals**
	- Pyramidal cels (CA3) → Pyramidal cells (CA1)
	
## 3.2 Additional Pathways
- EC → CA3 (parallel input of prefront pathway)
- EC → CA1/Subiculum = Temporo-ammonic pathway
	- Function: act as a 'comparator' of memories (CA3) vs current input (EC)
## 3.3 Special Properties
- CA3 = highly recurrent network
    - Auto-associative memory = Hopfield's network
    - Constant comparison between current input and input retreived from memory
- Layer specificity of EC ↔ HPC projections:
    - EC layer II/III → hippocampus
    - Hippocampus → EC layer V/VI

# 4. Inputs to Hippocampus

## 4.1 Cortical Inputs

- Mostly reach HPC via **entorhinal cortex**
	- Exception: perirhinal, parahippocampal cortex
- Highly processed, multimodal info
	- HPC does not receive direct input from visual/auditory cortices
- HPC lies at the convergence of visual streams:
    - **Dorsal stream** ("where", spatial): visual cortex → parietal cortex → retrosplenial cortex → parahippocampal cortex → HPC
    - **Ventral stream** ("what", object): visual cortex → temporal cortex → perirhinal cortex → EC → HPC

## 4.2 Subcortical Inputs

- Direct neuromodulatory input:
    - **Medial septum (ACh + GABA)** → Key link in 'limbic system' circuit
    - <font color="#245bdb">ACh → (spatial) memory encoding</font>
    - <font color="#245bdb">GABA → theta wave</font>
- Other modulators :
    - DA, 5-HT, NA

## 5.1 Theta State
- Occurs during:
    - Exploration / movement
- Function:
    - **Memory encoding + recall**
## 5.2 Large Irregular Activity (LIA)
- large-amplitude, irregular, low-frequency
- Occurs during:
    - Quiet wakefulness (resting) / slow-wave sleep
- Associated with:
	- Sharp wave ripples

# Example Questions

## Overview

The hippocampus is a key structure of the limbic system located in the medial temporal lobe, lying along the medial edge of the cortical sheet, which gives rise to its classification as part of the “limbic” cortex . It plays a central role in memory formation and spatial cognition, acting as a hub for integrating multimodal cortical inputs and transforming them into long-term representations.

Anatomically, the hippocampus is part of the **hippocampal formation**, which includes several interconnected components. The **hippocampus proper** is a <font color="#c00000">three-layered allocortex</font>, in contrast to the six-layered neocortex. It consists of the <font color="#c00000">dentate gyrus (DG), CA fields (CA1–CA3), and the subiculum</font>. The dentate gyrus serves as the <font color="#c00000">primary input region</font>, while the subiculum acts as a major <font color="#c00000">output structure</font>. Surrounding regions include the <font color="#c00000">presubiculum</font>, <font color="#c00000">parasubiculum</font>, and critically the **entorhinal cortex (EC)**, which serves as the <font color="#c00000">main interface between the hippocampus and the neocortical inputs</font>. Additional associated cortical areas include the <font color="#c00000">perirhinal and parahippocampal cortices</font>, which provide <font color="#c00000">highly processed sensory inputs </font>.

The intrinsic connectivity of the hippocampus is organised into the **tri-synaptic loop**, a largely unidirectional circuit. Information flows from the entorhinal cortex to the dentate gyrus via the **perforant pathway**, from the dentate gyrus to CA3 via **mossy fibres**, and from CA3 to CA1 via **Schaffer collaterals**, before returning to the entorhinal cortex. Additional pathways include direct projections from the entorhinal cortex to CA3 and to CA1/subiculum via the <font color="#c00000">temporo-ammonic pathway </font>. This organisation enables the hippocampus to <font color="#c00000">compare current sensory input with stored memory representations</font>.

A key functional property of the hippocampus arises from the CA3 region, which forms a <font color="#c00000">highly recurrent network</font>. This allows it to act as an **auto-associative memory system**, similar to a Hopfield network, supporting pattern completion and memory retrieval. The hippocampus therefore functions as a comparator, continuously evaluating incoming information from the entorhinal cortex against internally stored representations .

Inputs to the hippocampus are <font color="#c00000">highly processed and multimodal</font>. Cortical inputs converge via the entorhinal cortex, integrating information from both dorsal (spatial) and ventral (object-related) processing streams. Notably, the hippocampus does not receive direct input from primary sensory cortices. Instead, it lies at the convergence of dorsal and ventral visual streams. Subcortical inputs include <font color="#c00000">neuromodulatory projections</font> from the <font color="#c00000">medial septum</font>, which provide <font color="#c00000">acetylcholine and GABA</font>. These inputs are essential for <font color="#c00000">regulating hippocampal oscillatory states </font>and<font color="#c00000"> linking it to broader limbic system activity </font>.

The hippocampus exhibits distinct **oscillatory states** that are closely linked to its functional roles. During active exploration and movement, the hippocampus shows **theta oscillations**, which are associated with <font color="#c00000">memory encoding and retrieval</font>. These rhythms are generated in part by septal inputs. In contrast, during rest, eating, and slow-wave sleep, the hippocampus exhibits **large irregular activity (LIA)**, which is associated with <font color="#c00000">offline memory consolidation</font> .

Functionally, the hippocampus is critical for **declarative memory**, particularly<font color="#c00000"> episodic memory</font>, which involves the encoding of events in a specific spatial and temporal context. Semantic memory is less dependent on the hippocampus, while non-declarative forms of memory, such as procedural learning, priming, and conditioning, do not require hippocampal function. This distinction is supported by clinical evidence from patient H.M., who underwent bilateral removal of the hippocampus and surrounding structures. He exhibited <font color="#c00000">severe anterograde amnesia and some retrograde amnesia</font>, while <font color="#c00000">retaining short-term memory, procedural learning abilities, language, and general intelligence</font> . This demonstrates that the <font color="#c00000">hippocampus is essential for long-term memory formation</font> but not for all types of memory.

The hippocampus also plays a major role in **spatial cognition**, functioning as a cognitive map of the environment. Place cells in the hippocampus fire when an individual is in <font color="#c00000">specific locations</font>, while grid cells in the<font color="#c00000"> entorhinal cortex</font> provide a metric representation of space. Head direction cells encode <font color="#c00000">specific head orientation</font>, with signals transmitted through a pathway involving brainstem nuclei, <font color="#c00000">mammillary bodies, thalamus, and parahippocampal regions before reaching the hippocampus</font> . Together, these systems enable navigation and spatial awareness.

Finally, models of memory consolidation further illustrate hippocampal function. The<font color="#c00000"> standard consolidation theory</font> proposes that the hippocampus temporarily stores memories, which are gradually transferred to the neocortex for long-term storage. In contrast, the multiple trace theory suggests that the hippocampus remains necessary for rich episodic memories throughout life. These models highlight the dynamic role of the hippocampus in memory processing.

In summary, the hippocampus is a structurally specialised and functionally critical region that integrates multimodal inputs, processes them through a highly organised circuit, and supports memory formation and spatial representation.
