# Year 2 Study Notes

This is an unofficial, student-created revision notes for selected UCL NEUR0001/0002 Year 2 modules. This vault is intended to support personal study, peer learning, and constructive academic discussion. It is not an official University resource and may contain errors or omissions.

## Included modules

- ANAT0003 - Human Neuroanatomy
- BIOC0007 - Essential Molecular Biology
- NEUR0006 - Molecular Biology for Neuroscientists
- NEUR0007 - Cellular Neurophysiology
- PHAR0007 - Introductory Pharmacology
- PSYC0017 - Perception

Each module is organised in its own folder. The note titles generally follow the order of the taught material.

## Questions and revision material

This vault contains several types of question-based revision material:

- **ANAT0003 example questions:** each lesson is followed by AI-generated example questions to support preparation for the short-essay test.
- **Sample questions:** some modules include sample questions drawn from public mock papers. They remain subject to the terms and copyright of their original source.
- **Practice questions:** these are AI-generated practice questions based on notes. They are not past-paper questions, and are created only as revision aids.

Please use all question material critically and always prioritise the current module handbook, learning outcomes, and official teaching materials.

## Reading the vault in Obsidian

Obsidian is recommended because it preserves the internal links, embedded material, and folder structure used in these notes.

### Option 1: Download and read

1. On GitHub, select **Code** and then **Download ZIP**.
2. Extract the ZIP file to a permanent location on your computer.
3. Install the free [Obsidian desktop app](https://obsidian.md/download).
4. Open Obsidian and select **Open folder as vault**.
5. Choose the extracted `NEUR0001(0002)_YEAR2_NOTES` folder.
6. Use the File Explorer on the left to open a module, then open the numbered notes in order.

### Option 2: Fork and contribute

1. Sign in to GitHub and select **Fork** on this repository.
2. Create the fork under your own account.
3. Download or clone your fork, then open its root folder in Obsidian using **Open folder as vault**.
4. Make improvements in your fork and keep a clear record of material changes.
5. Submit a pull request if you would like to propose an improvement to this repository.

## Plugins

No community plugins are required for normal reading. The vault uses standard Obsidian Markdown features, including internal links, embedded files, callouts, and mathematical notation, which are supported by Obsidian itself.

The following optional community plugins may improve the experience of creating, editing, and navigating notes. They are not required to read this vault:

- **Editing Toolbar** by Cuman — provides a customisable, Word-like toolbar with built-in editing commands.
- **floating toc** by Cuman — displays a floating table of contents based on the headings in the current note.
- **Mousewheel Image zoom** by Nico Jeske — lets you increase or decrease the size of an image with the mouse wheel.

Please keep **Restricted Mode** enabled unless you have independently reviewed and chosen to trust a community plugin. To install one of the optional plugins:

1. Open **Settings**.
2. Select **Community plugins**.
3. Turn off **Restricted Mode** only if you trust the plugin.
4. Select **Browse**, search for the plugin by its exact name, then select **Install** and **Enable**.
