# 15. Attention (1) — Mock MCQ

1. Why is attentional selection necessary?
   a. Processing capacity is limited  
   b. Every input can be fully processed  
   c. Receptive fields never overlap  
   d. Sensory signals contain no competition

2. Early-selection theories propose that unattended information is filtered:
   a. Only after response execution  
   b. After all meanings reach awareness  
   c. In motor cortex only  
   d. Before full semantic analysis using simple physical features

3. Late-selection theories propose that selection occurs:
   a. In the retina before transduction  
   b. Before any physical feature analysis  
   c. After semantic processing  
   d. Before the sensory register

4. In a feature-search task, reaction time is normally:
   a. Impossible to measure  
   b. Nearly independent of set size  
   c. Proportional to set size  
   d. Twice as steep on every present trial

5. Finding a red item among green items is usually:
   a. Parallel, pre-attentive feature search  
   b. Serial conjunction search  
   c. Late semantic filtering  
   d. A Posner invalid trial

6. Finding a red square among red circles and green squares is usually:
   a. A single-feature pop-out  
   b. Independent of set size  
   c. An auditory oddball task  
   d. A conjunction search requiring focused attention

7. Why is the target-absent slope often about twice the target-present slope in conjunction search?
   a. Set size becomes irrelevant  
   b. Colour processing stops  
   c. All items may need to be checked before concluding absence  
   d. Absent targets pop out

8. Treisman and Gelade's (1980) Feature Integration Theory proposes that colour, shape and orientation are first processed:
   a. In auditory cortex  
   b. In separate pre-attentive feature maps  
   c. As fully bound objects  
   d. Only after a motor response

9. In Feature Integration Theory, focused attention binds features through a:
   a. Master map  
   b. Critical band  
   c. Horopter  
   d. Geon dictionary

10. An illusory conjunction occurs when:
   a. A target pops out accurately  
   b. One cue is more reliable  
   c. A sound is localised visually  
   d. Features from different objects are incorrectly bound

11. As the visual hierarchy ascends, receptive fields and competition generally:
   a. Remain constant  
   b. Become auditory  
   c. Both increase  
   d. Both decrease

12. The superior parietal lobule is especially associated with:
   a. Colour constancy  
   b. Top-down shifts and control of attention  
   c. Bottom-up salience only  
   d. Cochlear amplification

13. The inferior parietal lobule acts as a bottom-up “circuit breaker” for:
   a. Salient unexpected events  
   b. Voluntary semantic rehearsal only  
   c. Lens accommodation  
   d. Smooth pursuit only

14. The intraparietal sulcus is strongly associated with:
   a. Auditory critical bands  
   b. Face-space norms  
   c. Photoreceptor regeneration  
   d. Spatial priority maps

15. The frontal eye fields contribute to:
   a. Cochlear transduction  
   b. Rod scotopic vision  
   c. Eye-movement planning and voluntary attentional control  
   d. Colour-blindness diagnosis

16. Damage to the parietal attention network can produce:
   a. Akinetopsia only  
   b. Hemispatial neglect  
   c. Protanopia  
   d. Conductive deafness

17. Feedforward cortical processing primarily carries information:
   a. From lower to higher sensory areas  
   b. From higher areas back to lower areas  
   c. From motor commands to muscles only  
   d. Between the two ears

18. Feedback processing can provide lower sensory areas with:
   a. Only raw retinal input  
   b. Cochlear pressure amplification  
   c. No functional modulation  
   d. Context, prediction and attentional bias

19. The roughly 60-ms delay of responses to illusory versus real contours suggests:
   a. Feedback is faster than feedforward input  
   b. V1 cannot represent missing contours  
   c. Recurrent higher-level inference feeds back to early visual cortex  
   d. Illusory contours are detected by the retina alone

20. Participants search displays of 4, 8 and 16 items for either a uniquely coloured target or a colour-shape conjunction. Which outcome supports Feature Integration Theory?
   a. No measurable reaction times  
   b. Flat feature-search slope and positive conjunction-search slope  
   c. Positive feature slope and flat conjunction slope  
   d. Identical steep slopes for both

## Answers

1. a  2. d  3. c  4. b  5. a  
6. d  7. c  8. b  9. a  10. d  
11. c  12. b  13. a  14. d  15. c  
16. b  17. a  18. d  19. c  20. b
