# 13. Audition (1) — Mock MCQ

1. Sound is best described as:
   a. A transverse light wave  
   b. A static pressure field  
   c. A longitudinal pressure wave requiring a medium  
   d. An electromagnetic wave that travels in a vacuum

2. In a waveform, the x-axis and y-axis usually represent:
   a. Phase and colour  
   b. Time and amplitude  
   c. Frequency and time  
   d. Amplitude and frequency

3. In a spectrogram, frequency is plotted against time while shading usually represents:
   a. Amplitude  
   b. Phase  
   c. Direction  
   d. Retinal position

4. Which property is not directly displayed by a standard spectrogram?
   a. Frequency change over time  
   b. Relative amplitude  
   c. Number of spectral components  
   d. Component phase

5. The decibel scale is:
   a. Categorical  
   b. Retinotopic  
   c. Logarithmic  
   d. Linear

6. What is the approximate human auditory range?
   a. 20–200 MHz  
   b. 20–20,000 Hz  
   c. 400–780 Hz  
   d. 2–5 Hz

7. Human hearing is most sensitive around:
   a. 2–5 kHz  
   b. 20–50 Hz  
   c. 15–20 kHz  
   d. 100–120 kHz

8. Which function is served by the pinna?
   a. Converting vibrations into action potentials  
   b. Pumping cochlear fluid  
   c. Encoding binocular disparity  
   d. Elevation and front/back localisation

9. Auditory-canal resonance around 2–4 kHz especially enhances:
   a. Ultrasound only  
   b. Visual motion  
   c. Speech-relevant frequencies  
   d. Infrasound only

10. Which sequence correctly orders the middle-ear ossicles?
   a. Malleus → stapes → cochlea  
   b. Malleus → incus → stapes  
   c. Incus → stapes → malleus  
   d. Stapes → malleus → incus

11. The stapes transfers vibration to the:
   a. Oval window  
   b. Tympanic membrane  
   c. Pinna  
   d. Auditory cortex

12. The middle ear solves the air-to-fluid impedance mismatch mainly through:
   a. Tonotopic cortical maps  
   b. Phase locking only  
   c. Binaural rivalry  
   d. Tympanic-to-oval-window area ratio and ossicular leverage

13. Which cochlear location responds best to high frequencies?
   a. Middle ear  
   b. Pinna  
   c. Base  
   d. Apex

14. Inner hair cells primarily:
   a. Localise sound visually  
   b. Transmit sensory information to auditory-nerve fibres  
   c. Amplify basilar-membrane movement through shape change  
   d. Protect the tympanic membrane

15. Outer hair cells primarily:
   a. Provide cochlear amplification  
   b. Carry 95% of afferent output  
   c. Form the auditory nerve  
   d. Encode semantics

16. Which ion enters hair cells when stereocilia bend, initiating depolarisation?
   a. Cl−  
   b. Fe2+  
   c. I−  
   d. K+

17. Tonotopy refers to the mapping of:
   a. Phase onto colour  
   b. Time onto retinal eccentricity  
   c. Frequency onto spatial location  
   d. Loudness onto eye position

18. Phase locking contributes most strongly to coding:
   a. High-frequency place information only  
   b. Low-frequency sounds  
   c. All frequencies equally without limit  
   d. Colour gratings

19. Which sequence correctly describes the central auditory pathway?
   a. Cochlear nucleus → superior olive → inferior colliculus → MGB → A1  
   b. Superior olive → cochlea → LGN → V1  
   c. Pinna → FFA → V5 → A1  
   d. MGB → auditory nerve → cochlea → A1

20. A physiologist records firing rates from individual auditory-nerve fibres while presenting tones of different frequencies and intensities. This tests:
   a. Structural MRI contrast  
   b. Colour constancy  
   c. Late attentional selection  
   d. Single-cell frequency tuning and place coding

## Answers

1. c  2. b  3. a  4. d  5. c  
6. b  7. a  8. d  9. c  10. b  
11. a  12. d  13. c  14. b  15. a  
16. d  17. c  18. b  19. a  20. d
