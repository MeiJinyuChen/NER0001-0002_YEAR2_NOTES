
# 4. Visual System (2) — Mock MCQ

1. Which sequence correctly describes the principal visual pathway?
   a. Retina → optic chiasm → LGN → V1  
   b. Cornea → LGN → retina → V1  
   c. Retina → superior olive → LGN → V1  
   d. Retina → V1 → optic chiasm → LGN

2. Each LGN represents information from:
   a. Both eyes and the ipsilateral visual field  
   b. One eye and the contralateral visual field  
   c. One eye and both visual fields  
   d. Both eyes and the contralateral visual field

3. Which LGN layers receive contralateral-eye input?
   a. 3–6 only  
   b. 1, 4 and 6  
   c. 2, 3 and 5  
   d. 1 and 2 only

4. Parasol retinal ganglion cells project mainly to:
   a. Parvocellular layers 3–6  
   b. Magnocellular layers 1–2  
   c. Koniocellular interlayers only  
   d. V4 directly

5. Which stimulus should preferentially activate the magnocellular pathway?
   a. Rapid luminance flicker with coarse structure  
   b. A high-spatial-frequency colour boundary  
   c. A static blue-yellow patch  
   d. A fine, stationary red-green pattern

6. Which stimulus should preferentially activate the parvocellular pathway?
   a. Fine chromatic detail  
   b. A brief luminance transient  
   c. Rapid achromatic motion  
   d. Low-spatial-frequency flicker

7. Koniocellular cells receive major input from which retinal ganglion cells?
   a. Amacrine cells  
   b. Parasol cells  
   c. Midget cells  
   d. Bistratified cells

8. A blue-ON opponent cell compares:
   a. S-cone input against L+M input  
   b. L-cone input against M input  
   c. Rod input against all cones  
   d. L+M input against rods

9. Retinotopic organisation means that:
   a. Neighbouring retinal points map to neighbouring neural locations  
   b. Both eyes project to the same LGN layer  
   c. Central vision is underrepresented  
   d. Each layer represents a different colour

10. Why is the fovea magnified in LGN and cortex?
   a. It detects only motion  
   b. It receives no cone input  
   c. It contains mainly rods  
   d. It provides high-acuity central information

11. Magnocellular and parvocellular LGN inputs terminate mainly in which V1 layers?
   a. M in layers 2–3; P in layer 5  
   b. M in 4Cα; P in 4Cβ and 4A  
   c. M in 4Cβ; P in 4Cα  
   d. Both exclusively in layer 6

12. A V1 neuron responds to a vertical bar only when it occupies a specific ON/OFF arrangement. It is most likely a:
   a. Complex cell  
   b. Simple cell  
   c. Koniocellular cell  
   d. Retinal rod

13. A V1 neuron responds to an oriented bar across several positions within its receptive field. It is most likely a:
   a. Complex cell  
   b. Midget cell  
   c. Bipolar cell  
   d. Simple cell

14. An end-stopped cell decreases its firing when a bar extends beyond its preferred length. Such cells help encode:
   a. Lens accommodation  
   b. Auditory frequency  
   c. Object boundaries and curvature  
   d. Absolute wavelength only

15. Hubel and Wiesel's account proposes that a simple cell can be constructed from:
   a. Bilateral V5 lesions  
   b. Aligned LGN centre-surround inputs  
   c. A single S-cone  
   d. Unrelated auditory neurons

16. When an electrode moves vertically through an orientation column, preferred orientation typically:
   a. Remains similar  
   b. Reverses by 180° each layer  
   c. Becomes colour selective  
   d. Disappears completely

17. Ocular-dominance columns consist of alternating V1 regions preferentially driven by:
   a. Left and right eyes  
   b. Rods and cones  
   c. V4 and V5  
   d. Magnocellular and parvocellular cells

18. An fMRI experiment presents rotating wedges and expanding rings. What is it designed to map?
   a. Colour deficiency  
   b. Lens refraction  
   c. Retinotopy  
   d. Single-cell spike timing

19. Which pairing is correct?
   a. V3—motion; V4—form; V5—taste  
   b. V3—colour; V4—motion; V5—form  
   c. V3—form; V4—colour; V5—motion  
   d. V3—eye movement; V4—hearing; V5—colour

20. The “grandmother cell” hypothesis is an example of the claim that:
   a. Perception always depends only on population averages  
   b. A high-level neuron may directly represent a specific perceptual element  
   c. LGN layers mix both eyes completely  
   d. All V1 neurons respond identically

## Answers

1. a  2. d  3. b  4. b  5. a  
6. a  7. d  8. a  9. a  10. d  
11. b  12. b  13. a  14. c  15. b  
16. a  17. a  18. c  19. c  20. b
