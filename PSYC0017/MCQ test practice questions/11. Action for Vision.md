# 11. Action for Vision — Mock MCQ

1. The degrees-of-freedom problem refers to:
   a. Multiple movement solutions for the same goal  
   b. The number of cone types  
   c. The range of audible frequencies  
   d. The number of LGN layers

2. Choosing an action among kinematically redundant alternatives may consider energy cost, success probability and:
   a. Cone wavelength  
   b. Auditory phase  
   c. Eye colour  
   d. Movement comfort

3. An allocentric frame specifies a target relative to:
   a. The retina only  
   b. A motor neuron only  
   c. External objects or the world  
   d. The observer's body only

4. An egocentric frame specifies a target relative to:
   a. Auditory frequency  
   b. The self  
   c. Another external object only  
   d. Object semantics only

5. The posterior parietal cortex primarily helps transform:
   a. Visual representations into motor responses  
   b. Sound pressure into cochlear motion  
   c. Wavelength into cone photopigment  
   d. Faces into semantic names only

6. Which IPS region is most associated with saccade planning and predictive remapping?
   a. VIP  
   b. MIP  
   c. AIP  
   d. LIP

7. Which IPS region uses head/body-centred coding?
   a. MIP  
   b. AIP  
   c. VIP  
   d. LIP

8. Which IPS region is most associated with reaching?
   a. FFA  
   b. MIP  
   c. LIP  
   d. VIP

9. Which IPS region links visual object properties to grasping and hand shaping?
   a. AIP  
   b. LIP  
   c. VIP  
   d. V8

10. A neuron responds to object shape during fixation but not to an unseen grasp movement. It is most likely an AIP:
   a. Motor-dominant neuron  
   b. Auditory neuron  
   c. Retinal ganglion cell  
   d. Visual-dominant neuron

11. Saccadic remapping is thought to maintain:
   a. Auditory pitch  
   b. Lens transparency  
   c. A stable representation of the visual world  
   d. Colour naming

12. Gibson's (1979) term for an object's action possibilities is:
   a. Critical bands  
   b. Affordances  
   c. Geons  
   d. Metamers

13. Chao and Martin (1999) found that viewing graspable objects can automatically activate:
   a. AIP grasping circuits  
   b. Cochlear amplification  
   c. Colour-opponent channels  
   d. FFA only

14. Creem and Proffitt's (2001) semantic-distraction result suggests object use:
   a. Is entirely independent of cognition  
   b. Occurs only in V1  
   c. Requires no visual input  
   d. Can involve semantic/cognitive contributions

15. Milner and Goodale (1992) associated the dorsal stream with:
   a. Colour memory  
   b. Speech perception  
   c. Vision for action  
   d. Object recognition

16. Patient DF had bilateral ventral/LOC damage and showed:
   a. Cerebral achromatopsia only  
   b. Visual form agnosia with relatively preserved grasping  
   c. Optic ataxia with normal recognition  
   d. Akinetopsia

17. Patient RV had bilateral occipitoparietal damage and showed:
   a. Optic ataxia with relatively preserved perception  
   b. Prosopagnosia only  
   c. Colour agnosia  
   d. Visual form agnosia with preserved action

18. The contrasting patterns in DF and RV constitute:
   a. A psychometric function  
   b. Binocular rivalry  
   c. A critical band  
   d. A double dissociation

19. In the Ebbinghaus experiment, perception is often strongly biased while maximum grip aperture is less biased. This was initially taken as evidence for:
   a. Auditory dominance  
   b. Colour constancy  
   c. Separate visual analyses for perception and action  
   d. One completely unitary visual pathway

20. A patient accurately judges a slot's orientation verbally but cannot post a card through it. Which lesion-method interpretation is most likely?
   a. Retinal cone loss measured by fMRI  
   b. Dorsal-stream dysfunction identified through neuropsychological dissociation  
   c. Ventral-stream dysfunction measured by PET glucose  
   d. Cochlear dysfunction measured by EEG

## Answers

1. a  2. d  3. c  4. b  5. a  
6. d  7. c  8. b  9. a  10. d  
11. c  12. b  13. a  14. d  15. c  
16. b  17. a  18. d  19. c  20. b
