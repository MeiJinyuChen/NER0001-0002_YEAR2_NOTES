# 9. Object Perception — Mock MCQ

1. Which visual pathway is principally associated with object recognition?
   a. Auditory brainstem pathway  
   b. Retinotectal pathway only  
   c. Dorsal occipitoparietal stream  
   d. Ventral occipitotemporal stream

2. Which progression correctly describes increasing complexity and invariance along the ventral stream?
   a. LGN → MIP → FEF  
   b. IT → V4 → V1  
   c. V1/V2 → V4 → LOC/IT  
   d. V5 → AIP → cochlea

3. V4 neurons are especially tuned to:
   a. Shape curvature and orientation elements  
   b. Complete semantic biographies  
   c. Auditory pitch  
   d. Eye-muscle feedback

4. Damage to LOC/IT can cause:
   a. Akinetopsia only  
   b. Deafness  
   c. Hemianopia from retinal loss  
   d. Object agnosia

5. Selfridge's Pandemonium model is an example of:
   a. Efference-copy theory  
   b. Biased competition  
   c. Template/feature matching  
   d. Cue reliability weighting

6. Marr and Nishihara criticised early template matching because it would require:
   a. Direct access to 3D depth in the retina  
   b. Representations for many objects and viewpoints  
   c. No stored representations  
   d. Only one feature detector

7. In Marr's computational theory, which stage follows the input image?
   a. 3D model  
   b. Edge image  
   c. 2.5-D sketch  
   d. Semantic memory

8. Which stage in Marr's hierarchy is object-centred?
   a. Edge image  
   b. 2.5-D sketch  
   c. 3D model  
   d. Input image

9. Marr and Nishihara proposed which primitives for 3D object descriptions?
   a. Critical bands  
   b. Fourier phases  
   c. Generalised cones  
   d. Retinal rods

10. Biederman's recognition-by-components account proposes a vocabulary of about 36:
   a. Critical bands  
   b. Geons  
   c. Photopsins  
   d. Face norms

11. Which is a non-accidental property in Biederman's theory?
   a. Parallelism  
   b. Exact retinal size  
   c. Momentary illumination  
   d. Current eye position

12. Recognition is especially impaired when contours specifying _____ are obscured.
   a. Random mid-segments only  
   b. Retinal blood vessels  
   c. Auditory harmonics  
   d. Geons

13. A major strength of structural-description models is that they:
   a. Predict complete viewpoint dependence  
   b. Avoid extracting any shape  
   c. Explain invariance using economical combinations of parts  
   d. Require a separate template for every view

14. Which finding challenges fully viewpoint-invariant structural models?
   a. V1 is not orientation selective  
   b. Recognition depends on distance from trained views  
   c. All IT neurons respond identically to every viewpoint  
   d. Geons never affect recognition

15. Bülthoff and Edelman (1992) provided behavioural evidence that object recognition is:
   a. Viewpoint-dependent  
   b. Completely invariant  
   c. Based only on colour  
   d. Independent of learning

16. Logothetis, Pauls and Poggio (1995) found that most IT neurons were:
   a. Viewpoint-independent  
   b. Selective only for sound  
   c. Unresponsive to objects  
   d. Viewpoint-dependent

17. Riesenhuber and Poggio's model recognises objects by:
   a. Ignoring physiology  
   b. Comparing eye-muscle signals  
   c. Matching viewpoint-dependent representations to learned standard views  
   d. Using one innate 3D template

18. Güçlü and van Gerven found that deep-network nodes resemble the ventral stream's hierarchy from:
   a. Motor command to proprioception  
   b. Orientation to features to objects  
   c. Sound to action to colour  
   d. Depth to hearing to smell

19. Ponce et al. (2019) used a genetic algorithm to:
   a. Evolve images that strongly drive IT neurons  
   b. Create temporary human lesions  
   c. Measure auditory MMN  
   d. Estimate colour thresholds

20. A patient can detect edges and colours but cannot recognise visually presented objects following bilateral LOC damage. This pattern is best classified as:
   a. Akinetopsia revealed by psychophysics  
   b. Protanopia revealed by EEG  
   c. Neglect revealed by PET  
   d. Object agnosia revealed by neuropsychology

## Answers

1. d  2. c  3. a  4. d  5. c  
6. b  7. b  8. c  9. c  10. b  
11. a  12. d  13. c  14. b  15. a  
16. d  17. c  18. b  19. a  20. d
