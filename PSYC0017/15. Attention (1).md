

# 1. Definition of Attention

## Core Concept

Attention is the cognitive process that allows the brain to **select certain information for enhanced processing while filtering out irrelevant input**, due to limited processing capacity.

### Key Principle:

- **Processing resources are limited**
- Therefore:
    - Not all sensory input can be processed equally
    - A **selection bottleneck/filter** is necessary

## Bottleneck Model:

**Input → Filter/Selection Criteria → Output**

### Selection can occur at:

|Type|Description|Example|
|---|---|---|
|**Early Selection**|Filtering based on simple physical features before full semantic processing|Listening only to one voice in a noisy environment|
|**Late Selection**|Inputs processed semantically before selection|Meaning of unattended stimuli can still be processed|

# 4. Visual Search

## A. Feature Search
### Definition:
Searching for a target defined by **one unique feature**.
### Findings:
- Reaction time is **independent of set size**
- Processing is **parallel**
- Efficient and automatic
- Reflects **pre-attentive processing**
### Example:
Finding a red item among green items

## B. Conjunction Search
### Definition:
Searching for a target defined by **combination of features**
### Findings:
- Reaction time **increases with set size**
- Processing is **serial**
- **Requires focused attention**
- More cognitively demanding
### Example:
Finding a red square among red circles and green squares

## Search Slopes:

| Search Type        | Processing Mode | RT vs Set Size |
| ------------------ | --------------- | -------------- |
| Feature Search     | Parallel        | Flat           |
| Conjunction Search | Serial          | Positive slope |

### Important:
- Target absent trials ≈ slope doubles
- Because all items must be checked

# 5. Feature Integration Theory (Treisman & Gelade, 1980)

## Main Proposal:
### Stage 1: Pre-attentive Feature Maps
- Separate processing of:
    - Color
    - Shape
    - Orientation
### Stage 2: Focused Attention
- Features are bound together into coherent objects via a **master map**

## Key Lessons:
### Selection:
- Not all stimuli processed equally
### Binding:
- Attention integrates features into objects
### Competition:
- Multiple stimuli compete for representation

## Illusory Conjunctions:
### Occur when:
- Binding fails
- Features from multiple objects combine incorrectly
### Importance:
- Demonstrates that attention is required for accurate object perception

# 7. Cognitive Neuroscience Framework

## Main Idea:

Understanding attention requires understanding:

- Hierarchical neural systems
- Parallel pathways
- Competition between converging inputs
- Feedback and feedforward circuits

## Principles:

### A. Multiple Parallel Pathways
- Functionally specialized neurons
- No single visual object database

### B. Hierarchical Processing
- Higher levels:
    - Larger receptive fields
    - Greater convergence
    - More competition

# 9. Gross Anatomy of Attention Networks

## A. SPL (Superior Parietal Lobule)

### Function:
**Top-down attention**
### Roles:
- Controls attentional spotlight size
- Disengages from irrelevant stimuli
- Shifts attention
- Engages relevant targets

## B. IPL (Inferior Parietal Lobule)
### Function:
**Bottom-up attention**
### Roles:
- Detects saliency
- Reflexive attentional capture
- “Circuit breaker” for suddent, unexpected stimuli

## C. IPS (Intraparietal Sulcus)
### Function:
**Priority/attention maps**
### Roles:
- Spatial maps of attentional priority
- Attention activates IPS region (observed in fMRI)

## D. FEF (Frontal Eye Fields)
### Function:
- Eye movement planning
- Additional attentional maps
- Voluntary control

## Clinical Relevance:
### Damage to network →
**Hemispatial neglect**
- Neglect is usually related to parietal damage

# 12. Feedforward vs Feedback

## Feedforward:
- Lower → Higher areas
- Rapid sensory analysis

## Feedback:
- Higher → Lower areas
- Top-down modulation
- Context
- Prediction
- Attention bias

## Example:

### Illusory contours:
- Responses delayed ~60 ms compared to real contours
- Suggests:
    - Higher-level inference
    - Recurrent feedback to early visual cortex
(True contour: visual input → early visual response
  Illusory contour: partial visual input → higher-level interpretation → feedback to early visual cortex → representation of missing contour)
