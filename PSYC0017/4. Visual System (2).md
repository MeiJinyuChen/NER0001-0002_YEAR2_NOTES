

# 1. Lateral Geniculate Nucleus (LGN)

## Anatomical Pathway
### Basic Route:

**Retina → Optic chiasm → LGN (thalamus) → Visual cortex**
- Retinal ganglion cell axons partially cross at the **optic chiasm**
- Each LGN receives:
    - <span style="background:#fff88f">Input from both eyes</span>
    - <span style="background:#fff88f">Information from the **contralateral visual field**</span>
- LGN is located in the **thalamus**
- Some retinal fibres also project to:
    - **Superior colliculus** (important for eye movements)

### Structural Organisation:
- LGN contains **6 layers**
- Each layer receives input from only **one eye**
- Three maps from each eye
- Retinotopically organised
- Fovea is overrepresented due to high acuity demands

### Eye-specific layers:

| LGN Layer                                       | Eye Input                                                 |
| ----------------------------------------------- | --------------------------------------------------------- |
| <span style="background:#fff88f">1, 4, 6</span> | <span style="background:#fff88f">Contralateral eye</span> |
| 2, 3, 5                                         | Ipsilateral eye                                           |

# 2. LGN Cell Types

## Comparison of Visual Pathways

| Feature                        | Magnocellular (M)                                                         | Parvocellular (P)                                                   | Koniocellular (K)             |
| ------------------------------ | ------------------------------------------------------------------------- | ------------------------------------------------------------------- | ----------------------------- |
| LGN layers                     | 1–2                                                                       | 3–6                                                                 | Between layers                |
| Retinal input （ganglion cells) | Parasol cells                                                             | Midget cells                                                        | Bistratified cells            |
| Colour sensitivity             | No                                                                        | Yes                                                                 | Blue-only (S-cone)            |
| Spatial resolution             | Poor                                                                      | High                                                                | Low                           |
| Temporal resolution            | Excellent                                                                 | Poor                                                                | Variable                      |
| Receptive field size           | Large                                                                     | Small                                                               | Large                         |
| Main role                      | <span style="background:#fff88f">Motion, luminance, coarse “where”</span> | <span style="background:#fff88f">Fine detail, colour, “what”</span> | Blue-yellow colour processing |
| Response speed                 | Fast                                                                      | Slow                                                                | Less understood               |


---

## Functional Summary:
### Magnocellular:
- Fast
- Motion detection
- Monochromatic
- Low detail
- “Rough but quick”
### Parvocellular:
- Colour processing
- High detail
- Fine shape/form
- Slow processing
### Koniocellular:
- S-cone (blue) input
- ON-centre only
- No surround suppression
- Important for blue-yellow opponency

---

# 3. Stimulus Preferences

## Magnocellular Pathway:
Best activated by:
- Low spatial frequency
- High temporal frequency
- Flicker
- Motion
- Luminance contrast

## Parvocellular Pathway:
Best activated by:
- High spatial frequency
- Fine detail
- Colour contrast
- Pattern discrimination

---

# 4. LGN Receptive Fields

## General Principle:
LGN receptive fields resemble retinal ganglion cell receptive fields:
- Centre-surround organisation
- ON-centre or OFF-centre

## Magnocellular RFs:
- Large
- Monochromatic
- Spatially opponent
- Good for luminance contrast and edge detection

## Parvocellular RFs:
- Small
- Colour opponent
- Red-green or blue-yellow
![[Pasted image 20260513093211.png]]
### Example:
- Red (L-cone) ON centre
- Green (M-cone) OFF surround
This allows neurons to compute:
- Whether a region is relatively more red or green
- Colour boundaries
- Fine chromatic edges

---

## Importance of Opponency:

- Enhances contrast
- Supports colour discrimination
- Sharpens edges
- Fundamental to computer vision edge-detection algorithms

---

# 5. Colour Opponency

## Types:

| Opponent Type | Centre | Surround |
| ------------- | ------ | -------- |
| Red-ON        | L cone | M cone   |
| Green-ON      | M cone | L cone   |
| Blue-ON       | S cone | L+M      |
| Yellow-ON     | L+M    | S        |

---

## Functional Importance:

- Supports Hering’s opponent-process theory
- Explains afterimages and colour illusions
- Essential for accurate colour perception

---

# 6. Retinotopic Maps in LGN

## Definition:
Neighbouring points in the retina map onto neighbouring points in the LGN.

### Features:
- Preserves spatial layout of visual world
- Each LGN layer contains its own visual field map
- Fovea heavily magnified
- More cortical and thalamic tissue dedicated to central vision

### Consequence:

Higher processing power for:
- Reading
- Fine discrimination
- Object recognition

---

# 7. LGN Functional Recap

### LGN serves as:

- Relay station
- Organiser of parallel pathways
- Spatial and colour processor
- Retinotopic mapper
- Gateway to cortex

# 8. Primary Visual Cortex (V1)

## Basic Structure:

- First cortical stage of visual processing
- 6 layers

### Inputs:

| Pathway       | V1 Target      |
| ------------- | -------------- |
| Magnocellular | Layer 4Cα      |
| Parvocellular | Layer 4Cβ + 4A |

---

## Major Organisational Principles:

1. Ocular dominance columns
2. Orientation columns
	  - 1 mm-long hypercolumn
3. Retinotopic maps

# Cells in V1
## Simple Cells
![[Pasted image 20260512152343.png|250]]
### Location:
- <span style="background:#fff88f">Mainly layers 4 and 6</span>
### Key Function:
Detect bars/edges of a specific orientation at a precise location.
### Construction:
Simple cells are thought to arise from aligned LGN centre-surround inputs:
- Multiple ON-centre cells arranged in strips
- OFF-centre surrounds between strips
### Properties
- Maxican hat
- Phase sensitivity (activity varies with exact location = ON/OFF zones)
- Orientation/direction & position selective

## Complex Cells
![[Pasted image 20260512153338.png|250]]
### Location:
- <span style="background:#fff88f">Layers 2, 3, 5</span>
### Properties:
- Orientation selective
- <span style="background:#fff88f">Give both ON and OFF at every point within RF = Approximately the same response across the whole RF</span>
- <span style="background:#fff88f">Phase insensitivity (no fixed ON/OFF zones)</span>
- Some are motion-direction selective
### Possible Mechanism
- Simple cells that are all tuned to the same orientation, but in slightly different positions in space, could feed on to the complex cell which performs an OR operation
### Function:
Provide:
- Greater invariance
- Motion sensitivity
- Robust feature detection

## Hypercomplex Cells 
= End-stopped cells

- Prefers stimuli of a certain length
- Response falls if the stimuli exceeds a certain length

# 12. Ocular Dominance Columns

## Definition:
Alternating cortical columns responding preferentially to:
- Left eye
- Right eye
### Key Feature:
- Input remains segregated initially
- Supports binocular processing later

---

# 13. Orientation Columns
## Definition:
Vertical cortical columns where neurons share:
- Same preferred orientation
- Different receptive field positions
### Electrode Findings:
- Moving vertically:
    - Same orientation preference
- Moving horizontally:
    - Gradual shift in orientation preference
### Important Fact:
<span style="background:#fff88f">~80%</span> of V1 neurons are orientation selective

---

# 14. Overlapping Cortical Architecture

V1 simultaneously contains:

- Ocular dominance organisation
- Orientation maps
- Retinotopy

This creates a highly structured, efficient feature-extraction system.
