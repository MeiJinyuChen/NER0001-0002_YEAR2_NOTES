# 1. The Fundamental Problem of Depth Perception

## 1.1 3D World vs 2D Retina

- The physical world has **three spatial dimensions**.
- The retinal image is **two-dimensional**.
- Core question:  
    → _How does the brain recover depth (3rd dimension) from 2D input?_

## 1.2 The Inverse Problem

- The mapping from **world → retinal image is ambiguous**.
- A single retinal image can arise from **multiple possible 3D scenes**.
- Therefore:
    - Perception = **inference process** (Helmholtz, 1887)
- Solution:
    - The visual system uses **multiple depth cues**:
        - **Binocular cues**
        - **Monocular cues**

---

# 2. Binocular Cues to Depth

## 2.1 Binocularity (Ecological Basis)

- Predators:
    - **Frontal eyes**
    - Large **binocular overlap**
- Prey:
    - **Lateral eyes**
    - Wide **field of view**
- Not universal → depends on **ecological context**

## 2.2 Convergence & Accommodation

### Convergence (binocular, oculomotor cue)

- Eyes rotate inward to fixate near objects.
- Provides depth via **efference copy signals**.

### Accommodation (monocular cue)

- Lens changes shape:
    - **Ciliary muscles contracts → Len becomes rounder → near**
    - **Ciliary muscles relaxed → Len becomes flatter→ far**

## 2.3 Interocular Differences (Parallax)

- Inter-pupillary distance: **~50–75 mm**
- Each eye receives a **slightly different image**
- This creates **binocular parallax**
- One eye (dominant) acts as main reference

## 2.4 Binocular Disparity

- Key depth cue:
    - Objects project to **different retinal locations** in each eye

### Types:

- **Crossed disparity** = Negative disparity
    - Object is **closer than fixation**
- **Uncrossed disparity** = Positive disparity
    - Object is **farther than fixation**

## 2.5 Horopter

- Points in space with the same retinal position relative to fixation lie on the horopter:
    - Same distance to retinal position relative to fixation = **Zero disparity**
    - Same retinal position in both eyes
- Relative to horopter:
    - Closer → crossed disparity, smaller retinal position difference in near eye
    - Farther → uncrossed disparity, larger retinal position difference in near eye

---

## 2.6 Stereopsis & Devices

- **Stereoscopes (Wheatstone, 1838)**:
    - Present separate images → evoke depth
- **Anaglyphs**:
    - Use colour filters to separate images
- **Modern 3D displays**:
    - Polarised lenses or parallax barriers

---

## 2.7 Correspondence Problem

- Problem:
    - How does the brain match points between two eyes?
- Two possibilities:
    - Feature matching
    - Point-by-point matching

---

## 2.8 Random Dot Stereograms (RDS)

- Julesz (1960):
    - No identifiable features
    - Depth perceived from **disparity alone**
- Key implication:
    - Depth is computed via **global disparity processing**
    - Not simple feature matching

---

## 2.9 Limits of Binocular Vision

### Diplopia (double vision)

- Occurs when disparity exceeds **fusional range**
- Images cannot be fused

### Binocular Rivalry

- When images differ greatly:
    - Alternating perception between eyes
    - Caused by **neural competition**

---

## 2.10 Amblyopia & Stereo-blindness

- Amblyopia 弱视（两眼使用程度不同）:
    - Developmental disorder (prevalence: ~3–5%)
    - Causes:
        - **Anisometropia** 屈光参差（两眼近视程度不同）
        - **Strabismus (esotropia/exotropia)** 斜视（两眼不能正常对准同一目标）
- Consequence:
    - Reduced acuity
    - Loss of stereopsis

### Stereo-blindness

- ~2% complete; ~10% partial deficits
- Can improve with **training**
- Suggests **plasticity beyond critical periods**

---

## 2.11 Neural Basis

- V1 neurons sensitive to disparity:
    - **Near cells** → crossed disparity
    - **Far cells** → uncrossed disparity
- Disparity processing occurs in:
    - **Dorsal stream**
    - **Ventral stream**

---

# 3. Monocular Cues to Depth

## 3.1 Motion Parallax

- Depth from **self-motion**
- Key principle:
    - **Near objects move faster**
    - **Far objects move slower**

### Direction Rule:

- Relative to fixation:
    - Near objects → move **opposite direction**
    - Far objects → move **same direction**

---

## 3.2 Pictorial Cues (2D cues)

### 3.2.1 Occlusion

- Occluding object = **closer**

### 3.2.2 Shading & Shadow

- Indicate:
    - Shape
    - Depth
- Based on **light-from-above assumption**

### 3.2.3 Perspective

- **Linear perspective**:
    - Parallel lines → converge
- **Textural perspective**:
    - Texture becomes denser with distance
- **Aerial perspective**:
    - Distant objects appear:
        - Hazy
        - Bluish (Rayleigh scattering)

---

## 3.3 Relative Size & Emmert’s Law

- Retinal size depends on distance
- If retinal size is constant:
    - **Farther object must be larger**

---

## 3.4 Size Constancy

- Perceived size remains constant despite retinal changes

### Breakdown:

- Illusions (e.g., Ponzo illusion)

### Neural Evidence:

- V1 activity reflects **perceived size**, not retinal size

---

## 3.5 Artificial Manipulations

- **Forced perspective** (films)
- **Ames room**:
    - Distorts size-distance relationship
    - Uses monocular viewing

---

# 4. Cue Combination

## 4.1 Cue Conflict

- Depth cues can conflict
- Studied by:
    - Putting cues in **competition**

---

## 4.2 Cue Integration

- Brain combines cues based on:
    - **Reliability (precision)**
- Key weighting:
    - **Binocular disparity** → highly reliable (especially near)
    - **Motion parallax** → strongest monocular cue
    - **Pictorial cues** → useful but can mislead

---

## 4.3 Why Multiple Cues?

- Solve ambiguity (inverse problem)
- Different cues work best at **different distances**
- Combining cues → **most accurate depth perception**

---

# 5. Summary (High-Yield)

- Depth perception = inference from **ambiguous 2D input**
- **Binocular disparity** = primary cue for near depth
- **Monocular cues** provide depth when one eye is used
- Visual system performs:
    - **Cue integration**
    - Weighted by reliability

---

# 6. High-Yield MCQ Points

## Core Concepts

- Inverse problem → **multiple interpretations of retinal image**
- Depth perception = **inference process**
- Horopter = **zero disparity**

## Binocular Cues

- Crossed disparity → **near**
- Uncrossed disparity → **far**
- Inter-pupillary distance: **~50–75 mm**
- Diplopia occurs when disparity exceeds **fusional range**
- RDS → evidence for **global disparity processing**

## Monocular Cues

- Motion parallax:
    - Near = faster, opposite direction
- Occlusion = strongest pictorial cue
- Light-from-above assumption critical for shading
- Emmert’s law: same retinal size → farther = larger

## Neural & Clinical

- V1 contains disparity-selective neurons
- Amblyopia → loss of stereopsis
- Stereo-blindness can be **improved with training**

## Cue Combination

- Brain weights cues by **reliability**
- Best performance = **combined cues**
