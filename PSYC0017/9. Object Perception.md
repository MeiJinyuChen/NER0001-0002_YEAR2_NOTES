
# 1. Ventral Stream for Object Perception

**V1/v2**
- encode basic visual feature (edge orientations and spatical location)
- space-dependent
- small receptive fields
**V4**
- encode shape elements (shape curvature and orientation elements)
- more space-invariant
- medium receptive fields
**LOC & IT (lateral occipital and inferotemporal cortex)**
- encode complex objects
- highly space-invariant

## 1.1 V4

- Individual cells in V4 are tuned to shape elements
- By combining response of V4 cells with different tuning ('population'), the seen shape can be reconstructed

## 1.2 LOC/IT

### Object-selective neurons

- Neurons in IT show preferential responses to complex objects e.g. faces and hands
- Neurons with similar shape prefere cluster together in micro-columns in IT

### Macro-scale Category-selective Regions

- Lateral regions:
  Prefer faces/animals (e.g. fusiform area)
- Medial regions:
  Prefer houses/tools (e.g. parahippocampal place area)

### Damage of LOC/IT:

- Cause object agnosias

# 2. Models of Object Recognition

1. View dependent models: Template/feature matching models (60's)
2.  Strutural descrption models (80's)
3. View dependent models revisited (90's to now)

## 2.1 Template/feature Matching Models

### 2.1.1 Concept

- Feature detector:
  Brain contains templates f objects and can match those templates to an image
- Taking inspiration from Hubel and Wiesel's simple cell feature detectors on LGN/V1

### 2.1.2 Cons

- Can explain scale &translation of templates, but not distortion, so performance is poor

### 2.1.3 Example

**Selfridge's Pandemonium model**
- Resembles connectionist neural network: 
  Patterns of image features are feed in, and the network learns to map this object classes by adjusting how feature-induced activation get passed on through the network

### 2.1.4 Criticism

e.g. Marr & Nishihara, 1978:
- Template and feature matching requires representations of all possible objects/features from all possible viewpoints, which is computationally implausible

## 2.2 Structural Description Models

### 2.2.1 Concepts & Evolution

#### **Marr's Computaional Theory of Vision:**

##### Definition

- Vision is a computational process that transforms a 2D retinal image into a 3D representation of the world.

##### Concept

- Complex objects can be represented as "generalised cones + spatial relations" in 3D model.
- An object can be described in different hierachy (process level)

| Type         | Definition                                                                                                                                   | Centred        | Process level (hierachy) |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | -------------- | ------------------------ |
| Input image  | Retinal image: intensity and wavelegnth of light at each point                                                                               | Viewer-centred | 1 (lower)                |
| Edge image   | Zero crossing, blobs, bars, ends, curves, boundaries                                                                                         | 同上             | 2                        |
| 2.5-D sketch | Surfaces, with local orientations and discontinuities in depth                                                                               | 同上             | 3                        |
| 3-D model    | Use sharp concavities to divide surfaces into 3D "primitive" object elements: make up by **generalised cones** that vary in axis and volumes | Object-centred | 4 (higher)               |

##### Cons

- Generalised cones turned out difficult to derive from images

#### Biederman (1987):

##### Definition

- Vision relies on "non-accidental properties", which are features that remain stable across any 2D projection of a 3D object viewed from various angles (e.g. collinearity, symmetry, parallelism)
- Object recognition uses a vocabulary of basic shapes called geons: a set of ~36 shapes

##### Behavioural evidence

- Recognition is more impaired by obscuring geons than equal amounts of other contour information

### 2.2.2 Pros and Cons of Structural Description Models

| Pros                                                                              | Cons                                                                                                               |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Explain invariance well                                                           | Difficult to explain the discrimination between subtly different individuals within a class (super-ordinate level) |
| Use combinatorial power to create very memory effecient object representations    | Extracting volumes can be hard in real images (e.g. occulusion), and successful algorithms are still missing       |
| Evidence that non-accidental properties are particularly relevant for recognition | **Human perception and many IT neurons are NOT viewpoint invariant**                                               |

## 2.3 View-dependent Models Revisited

### 2.3.1 Evidence from perception

- Human perception is viewpoint-dependent **(Bulthoff & Edelman, 1992)**
- Most IT neurons are viewpoint-dependent, some are tuned to multiple known views, and only a very small number are viewpoint-independent **(Logothetis, Pauls & Poggio, Curr Bio, 1995)**

### 2.3.2 Computational Model (Riesenhuber & Poggio, 1999, 2000)

1. Derive viewpoint-dependent shape representations
2. Match image to stored standard view learnt from a few orientations. Good match = recognition

### 2.3.3 Evidence from deep learning models

- The node tuning properties in DL models resemble hierachical orientation-to-feature to object representations in ventral stream (Guclu & van Gerben, 2015)

### 2.3.4 Unsolved questions

- IT neurons are equally sensitive to abstract versions and parts of complex objects (geon-like shapes?)
- A modern approach to discover the best stimulus driving IT neurons: images that are created by a genetic algorithm from random textures (Ponce et al., 2019)
  (e.g. IT cells selective for monkey faces respond even better to complex scene textures with monkey-like features)
- IT neurons may not simply encode complex isolated objects

### 2.3.5 Pros and Cons of View-dependent Models

| Pros                                                             | Cons                                                                                                                             |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Straightforward, minimise transformations that must be performed | More memory & learning intensive the e.g. geon models                                                                            |
| Newer models based diretly on what we know of physiology         | Evidence that IT might be more selective for simplified object parts, or abstract textures rather than naturalistic object views |
| Abstract feature units are recombinable                          |                                                                                                                                  |
| Good behavioural, physiological and computational evidence       |                                                                                                                                  |
