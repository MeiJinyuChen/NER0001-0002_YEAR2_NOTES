# 1. Auditory Scene Analysis (ASA)

## Definition:
How the brain separates and identifies different sound sources in a complex environment.
### Equivalent to:
- Vision: object segmentation
- Audition: source segregation

---

# 2. Critical Bands

## Definition:
A **critical band** is the range of frequencies that stimulate the same cochlear region.
## Consequences:
### If frequencies are:
### Outside same critical band:
- Perceived as separate tones
### Inside same critical band:
- Interfere perceptually
- Produce beating/roughness
## Example:

|Frequency Pair|Percept|
|---|---|
|400 Hz + 510 Hz|Separate|
|400 Hz + 480 Hz|Roughness / beating|
- Critical bands limit frequency resolution.

# 9. Auditory Streaming

## Definition:
Continuous segregation of sound into perceptual streams.

## Example:
Repeated A-B tone sequences:
- Small frequency difference → one stream
- Large frequency difference → two streams

## Key Features:
- Dynamic
- Depends on context
- Can change over time

# 10. Bi-Stable Auditory Perception

## Definition:
One acoustic input can yield two valid interpretations.
### Characteristics:
- Perception alternates spontaneously
- Similar to visual bistability (e.g., Necker cube)
## Significance:
- Brain actively interprets rather than passively records
- Perception influenced by prediction

# 12. Mismatch Negativity (MMN)

## Definition:
An ERP/MEG response to unexpected deviations in auditory patterns.
## Characteristics:

| Feature               | Value                                  |
| --------------------- | -------------------------------------- |
| Latency               | 150–250 ms                             |
| Location              | Supratemporal auditory cortex          |
| Attention requirement | Pre-attentive (attention not required) |
| Paradigm              | Oddball                                |

## Interpretation:
MMN reflects discrepancy between:
- Predicted sensory input
- Actual input

## Clinical/Research Importance:

| Use                          | Explanation                                                                                                                  |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Pre-attentive discrimination | No conscious report required                                                                                                 |
| Clinical testing             | Useful in infants or impaired populations                                                                                    |
| Pattern learning             | Reveals sensitivity to features of sound<br>→ Reveals what kinds of patterns in the acoustic environment are we sensitive to |

# 16. Developmental Differentiation

## Infants:
### 0–6 months:
- Universal phonetic discrimination
### ~10–12 months:
- Specialization for native language
- Reduced discrimination of non-native contrasts

## Examples:

|Contrast|Population Losing Sensitivity|
|---|---|
|/r/ vs /l/|Japanese infants|
|Hindi contrasts|English infants|
