
# 1. Why Vision for Action is Challenging

## A. Action Complexity

Vision for action is not simply about perceiving the environment—it requires transforming visual information into efficient motor output.

### Key Insight:

Even simple movements involve highly complex visuomotor computations.

---

## B. Degrees of Freedom Problem

### Definition:

**Degrees of freedom** = Multiple possible movement solutions for achieving the same action goal.

### Example:

A football player can strike a ball using many different body configurations.

### Related Concepts:

- **Kinematic redundancy**
- **Motor equivalence**

### To select the ideal action, the brain evaluates:

| Factor              | Description                                  |
| ------------------- | -------------------------------------------- |
| Visual analysis     | Careful assessment of environment            |
| Cost prediction     | Energy expenditure, biomechanical efficiency |
| Success probability | Likelihood of achieving goal                 |
| Movement comfort    | Ergonomics and stability                     |

### Advantages:

- Minimises cost
- Maximises flexibility
- Maximises resistance to perturbation

### Disadvantage:

- Computationally demanding selection process

---

# 2. Visuomotor Transformations

## Core Problem:

The brain must determine:
1. Where limbs are relative to the target
2. How visual information is converted into motor commands

### Example:

Pouring water:
- Locate glass
- Represent hand, arm, teapot position
- Calculate movement trajectory

---

# 3. Frames of Reference (FOR)

## Definition:

A **frame of reference** is a coordinate system used to specify object location.

| Frame Type  | Definition                         |
| ----------- | ---------------------------------- |
| Allocentric | Relative to external objects/world |
| Egocentric  | Relative to self                   |

## Task-Specific FOR Use

| Task          | Optimal FOR     |
| ------------- | --------------- |
| Locate glass  | Glass vs eyes   |
| Pick up glass | Glass vs body   |
| Pour drink    | Teapot vs glass |

### Key Principle:

Different tasks require different coordinate systems.

---

# 4. Posterior Parietal Cortex (PPC) and Intraparietal Sulcus (IPS)

## PPC Functions:

- Receive visual input from V1/V2/V3
- Transform visual representation into motor response
- Project to (pre) motor cortex directly or indirectly (via prefrontal cortex / inferotemporal cortex)

## IPS Subregions

|Region|Function|
|---|---|
|LIP (Lateral Intraparietal Area)|Eye movements, saccade prediction|
|VIP (Ventral Intraparietal Area)|Vision + head/body-centred processing|
|MIP (Medial Intraparietal Area)|Reaching movements|
|AIP (Anterior Intraparietal Area)|Grasping and hand shaping|

### Functional Roles of Key IPS Regions

#### A. LIP – Eye Movements and Prediction

##### Functions:

- Projects to frontal eye fields
- Plans saccades (RF shifts before eye movement)
- LIP neuron RF shifts with covert attention (visual attention and anticipation)

##### Important Mechanism:

###### Saccadic Remapping

- Receptive fields shift before eye movement
- Maintains perceptual stability of external visual world, despite frequent changes of retinal signal (~3 saccades/second)

###### Efference Copy:

- Copy of motor command sent to sensory systems to predict movement consequences.

#### B. VIP – Body/Head-Centred Coding

##### Functions:

- Encodes body/head-centred FOR
- RF anchored to face position, not retina

#### C. MIP – Vision to Action Transformation

##### Functions:

- Transforms spatial location of a target into representation that can be used for reach by motor system
- Uses retinotopic FOR
- Stronger response for active reaching towards a target than passive motion of it

#### D. AIP – Manual Grasping

##### Functions:

- Links visual properties to manual grasping

##### Neuron Types:

| Type            | Encode            | Response to                                  |
| --------------- | ----------------- | -------------------------------------------- |
| Visual-dominant | Object shape only | Observed grasp + Object fixation             |
| Motor-dominant  | Grasp movement    | Observed/Non-observed gasp                   |
| Visuomotor      | Both              | Observed/Non-observed gasp + Object fixation |

# 5. Gibson’s Direct Perception Theory (1979)

## Core Idea:

Perception directly specifies action possibilities (**affordances**).

### Affordance:

An object's action possibilities based on:
- Visual features
- Observer goals

### Examples:

- Chair → Sitting
- Handle → Holding
- Button → Push
- Knob → Rotate

## Evidence:

### Chao & Martin (1999):

Viewing/Using/Categorizing  graspable objects activates AIP grasping circuits automatically.

### Challenge:

### Creem & Proffitt (2001):

Semantic distraction impairs typical object use.

### Conclusion:

Affordance processing may involve some semantic/cognitive contribution.

---

# 6. Dual Visual Streams Hypothesis (Milner & Goodale, 1992)

## Visual Pathways:

- Two interconnected but independent pathways

|Stream|Pathway|Function|Reference Frame|
|---|---|---|---|
|Ventral|Occipital → Temporal|Perception/recognition ("What")|Allocentric|
|Dorsal|Occipital → Parietal|Action guidance ("How/Where")|Egocentric|

---

# 7. Neuropsychological Evidence

## A. Patient DF – Visual Form Agnosia

### Damage:

- Ventral stream
- Bilateral ventrolateral lesions
	- Lateral occipital complex (LOC)

### Deficits:

- Cannot recognise complex objects
- Cannot accurately perceive object orientation
- Can accurately grasp/post object

### Interpretation:

Perception impaired, action intact.

## B. Patient RV – Optic Ataxia

### Damage:

- Dorsal stream
- Bilateral occipitoparietal lesions
	- Posterior parietal cortex (PPC)

### Deficits:

- Can perceive object properties
- Cannot accurately guide grasp

### Interpretation:

Action impaired, perception intact.

---

# 8. Double Dissociation

## Definition:

Two lesions selectively impair two separate functions.

|Lesion|Deficit|
|---|---|
|Ventral damage|Perception impaired|
|Dorsal damage|Action impaired|

### Significance:

Strong support for partial functional independence of dorsal and ventral streams.

### Limitation:

Does not prove absolute independence due to interconnected brain systems.

---

# 9. Perceptual Illusions and Vision for Action

## Ebbinghaus Illusion

### Finding:

- Perception strongly affected
- Grasp aperture often less affected

### Initial Interpretation:

Separate visual analyses for perception and action.

## Later Evidence:

- Illusions can influence planning
- Online visual feedback reduces illusion effects

### Conclusion:

Action system may not be entirely immune to perceptual distortions.
