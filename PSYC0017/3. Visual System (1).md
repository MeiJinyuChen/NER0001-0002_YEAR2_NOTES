

# 1. LIGHT AND THE EYE
## 1.1 Visible Light
### Key Facts
- Visible light is the human-detectable portion of the electromagnetic spectrum.
- Approximate visible wavelength range:
    - **400 nm** = violet/blue (short wavelength, high frequency)
    - **780 nm** = red (long wavelength, low frequency)
### Important Relationships

|Colour|Wavelength|Frequency|
|---|---|---|
|Blue/Violet|Shorter|Higher|
|Red|Longer|Lower|
### Core Principle
- Frequency and wavelength are inversely related.
- White light contains multiple wavelengths.

## 1.2 Lenses and Refraction
### Prism
- Splits white light into component colours because:
    - Different wavelengths refract by different amounts.
### Eye Optics
#### Cornea
- Main refractive structure.
- Performs most light focusing onto retina.
#### Lens
- Fine-tunes focus.
- <span style="background:#fff88f">Changes curvature (accommodation)</span> to focus objects at different distances.
## 1.3 Visual Defects

| Condition                   | Cause                                     | Result                                                               |
| --------------------------- | ----------------------------------------- | -------------------------------------------------------------------- |
| Myopia (near-sightedness)   | Eyeball too long / excessive focusing     | Light is focused in front of the retina<br>→ Distant objects blurred |
| Hyperopia (far-sightedness) | Eyeball too short / insufficient focusing | Light is focused behind the retina<br>→ Near objects blurred         |

## 1.4 Embryonic Development of the Eye
### Developmental Origins
### Brain-derived structures:
- Retina
- Optic nerve
### Surface ectoderm (skin)-derived structures:
- Lens
- Cornea
### Key developmental stages:
- Optic cup forms from neural tissue.
- Optic stalk contributes to optic nerve.
- Surface ectoderm folds inward to form lens.
### Exam Importance
- Retina and optic nerve are technically CNS tissue.
- Eye is not merely peripheral sensory tissue.

## 1.5 Eye & Light Recap
- Visible light: **400–780 nm**
- Cornea + lens focus light onto retina.
- Retina and optic nerve are extensions of the brain.

# 2. THE RETINA

## 2.1 Basic Structure
### Important Feature
- Retina is inverted:
    - Light passes through ganglion cells and interneurons before reaching photoreceptors.
### Consequence
- Blood vessels and exiting nerve fibres lie in front of photoreceptors.
## 2.2 Photoreceptors
### Rods vs Cones

| Feature            | Rods                   | Cones                    |
| ------------------ | ---------------------- | ------------------------ |
| Number             | ~120 million           | ~6 million               |
| Types              | 1                      | 3 (L, M, S)              |
| Photopigment       | Rhodopsin              | Photopsins               |
| Light Sensitivity  | Very high              | Lower                    |
| Function           | Night/scotopic vision  | Daylight/photopic vision |
| Colour Vision      | No                     | Yes                      |
| Spatial Resolution | Low                    | High                     |
| Distribution       | Peripheral retina      | Concentrated in fovea    |
| Photon Detection   | Single photon possible | Less sensitive           |
### Rod Characteristics
- Sensitive to blue-green wavelengths.
- Essential for low-light vision.
- Absent from fovea.
- Dominant in peripheral retina.
### Cone Characteristics
- Three opsin classes:
    - L-cones (red)
    - M-cones (green)
    - S-cones (blue)
#### Function
- Colour discrimination
- High acuity central vision

## 2.3 Dark Adaptation
![[Pasted image 20260513091529.png|550]]
### Mechanism
- In bright light:
    - Rods become bleached.
    - Sensitivity reduced.
- In darkness:
    - Rhodopsin regenerates.
    - Rod sensitivity increases.
### Timing
- Full dark adaptation:
    - Approximately **20–30 minutes**
    
## 2.4 Distribution of Photoreceptors
### Fovea
- Dense cones
- No rods
- Highest visual acuity
### Peripheral Retina
- Rod-dominant
- Better motion and dim-light detection

## 2.5 Retinal Circuitry
### Horizontal Cells
- Connect neighbouring photoreceptors.
- Mediate:
    - Lateral inhibition
    - Contrast enhancement
    - Dark adaptation
### Bipolar Cells
- Connect photoreceptors to ganglion cells.
### Amacrine Cells
- Intermediate retinal processing.

## 2.6 Retinal Ganglion Cells (RGCs)

### Numbers
- **~1.5 million** ganglion cells
- Compress input from:
    - **120 million** rods
    - **6 million** cones
### Function
- Output neurons of retina
- Axons form optic nerve

## 2.7 Major RGC Types

### Midget Cells (Parvocellular-like)

| Property           | Description                                             |
| ------------------ | ------------------------------------------------------- |
| Receptive Field    | Small                                                   |
| Spatial Resolution | High                                                    |
| Colour Selectivity | Strong                                                  |
| Response           | <span style="background:#fff88f">Slow, sustained</span> |
#### Specialization
- Fine detail
- Colour processing
### Parasol Cells (Magnocellular-like)

| Property           | Description                                             |
| ------------------ | ------------------------------------------------------- |
| Receptive Field    | Large                                                   |
| Spatial Resolution | Lower                                                   |
| Colour Selectivity | Poor                                                    |
| Response           | <span style="background:#fff88f">Fast, transient</span> |
#### Specialization
- Motion
- Temporal processing

## 2.8 Receptive Fields
### Centre-Surround Organization
- Circular receptive fields
- Spatial opponency (“Mexican hat” profile)
### ON-centre cells:
- Light in centre → excitation
- Light in surround → inhibition
### OFF-centre cells:
- Opposite pattern

ON and OFF pathways use different chemicals
- e.g. ON pathway can be blocked by APB
  → <span style="background:#fff88f">In daytime condition: Can spot light, but cannot spot dark. In night condition: fully blind.</span>
  → Both systems are required in normal vision.

### Functional Consequences

|Stimulus Location|Effect|
|---|---|
|Centre only|Increased firing|
|Surround only|Decreased firing|
|Both equally|Minimal/no net response|
